# BarSys: Inventory Evidence Tool

**BarSys** is a lightweight tool designed for bar owners and managers to create verifiable evidence of stock levels. Built to bridge the gap between "what the POS says" and "what is actually on the shelf".

---

## 🍺 Why BarSys?
In the hospitality industry, "shrinkage" (unaccounted-for stock loss) is a silent killer. BarSys allows staff to quickly document physical stock during shift changes or deliveries, providing a digital trail.

## ✨ Core Features
* **Rapid Stock-Take:** Mobile-optimized interface for counting stock. 
* **Export for Accountants:** Generate export in CSV or XLSX for tax or insurance purposes.
* **Dual mode:** Differentiate between stock mode and invetory check mode to insure consistent live refreshing data.
* **QR Menu:** Possibility to create a QR code to view in app changable menu.
